# كتابة المقالات من Obsidian

كل مقالة في الموقع لها ملف Markdown هنا في `content/articles/` (والإنجليزية في `content/articles/en/`).
لما ترفع ملف جديد أو تعدّل ملف موجود، GitHub يبني صفحة المقالة بتصميم الموقع، ويضيف بطاقتها في
الصفحة الرئيسية أو يحدّثها، ويحدّث RSS. خلال دقيقتين تقريبًا يظهر التغيير في الموقع.

## شكل الملف

```markdown
---
title: "عنوان المقالة"
summary: "سطر واحد يظهر تحت العنوان وفي البطاقة وفي RSS"
lang: ar
date: 2026-10-30
status: draft
---

نص المقالة هنا...
```

| الخانة | معناها |
|---|---|
| `title` | العنوان |
| `summary` | الملخص، سطر واحد |
| `lang` | `ar` أو `en` |
| `date` | تاريخ النشر بصيغة `2026-10-30` |
| `slug` | اسم الملف في الرابط (اختياري). لو تركته، يُترجم العنوان العربي للإنجليزي تلقائيًا مثل لوحة التحكم، ويُكتب في الملف حتى ما يتغير الرابط بعدين |
| `status` | `draft` = مسودة ما تنشر، `published` = تنشر |

**النشر = غيّر `status: draft` إلى `status: published` وارفع.**
**التعديل = عدّل الملف وارفع.** المقالة نفسها تتحدث، ما تتكرر.

## الكتابة

| تكتب | يطلع |
|---|---|
| `## عنوان` و `### عنوان فرعي` | عناوين الأقسام |
| `**غامق**` و `*مائل*` | **غامق** و *مائل* |
| `H~2~O` و `m^2^` | رقم سفلي وعلوي |
| `- عنصر` أو `1. عنصر` | قائمة |
| `> نص` | اقتباس |
| `[النص](https://...)` | رابط |
| `$E=mc^2$` و `$$ \frac{a}{b} $$` | معادلة |
| `$\ce{2H2 + O2 -> 2H2O}$` | صيغة كيميائية |
| `![[صورة.png\|وصف الصورة]]` | صورة (لازم ملف الصورة يكون داخل مجلد الموقع) |
| `%% ملاحظة %%` | ملاحظة لك، ما تظهر في الموقع |

## الاستشهاد من Zotero

| تكتب | يطلع |
|---|---|
| `[@parkAdvancesSnO2Efficient2021]` | (Park & Zhu, 2022) برابط للورقة |
| `[@saliba2016, p. 1990]` | (Saliba et al., 2016, p. 1990) |
| `[@saliba2016; @gratzel2021]` | (Saliba et al., 2016; Grätzel, 2021) |
| `[-@saliba2016]` | (2016) بدون اسم المؤلف، لما يكون الاسم مذكور في الجملة |

- في Obsidian: `Ctrl + P` ← **Zotero Integration: Cite**، واختر الورقة، فتنكتب لك تلقائيًا.
- قائمة **المصادر** تنضاف لحالها في آخر المقالة بأسلوب APA، بالترتيب الأبجدي. ولو كتبت `## المصادر`
  (أو `## References`) في مكان معين، تنحط القائمة تحته.
- البيانات تجي من `content/references.json`، وهو ملف يحدّثه Better BibTeX في Zotero تلقائيًا. لو
  استشهدت بورقة مو موجودة فيه، النشر يوقف ويقولك أي ورقة.

## المقالات القديمة

المقالات اللي كانت موجودة قبل هذا النظام مكتوب فيها `layout: existing`. يعني الصفحة تحتفظ بتصميمها
الخاص (الرسومات التفاعلية، روابط الترجمة)، والتعديل يغيّر النص بس. الأجزاء اللي بين
` ```html ` و ` ``` ` هي أجزاء خاصة (رسومات وأزرار)؛ تقدر تعدّل النص اللي فيها، بس انتبه للوسوم.

## انتبه

- **عدّل المقالة من مكان واحد.** لو عدّلت مقالة من «تعديل الصفحات» في لوحة التحكم، تعديلك بيضيع
  أول ما تعدّل ملف الـ Markdown حقها. خلّ Obsidian هو مكان التعديل.
- **الحذف من لوحة التحكم** (المقالات ← حذف). يحذف الصفحة والبطاقة وRSS وملف الـ Markdown مع بعض.
  حذف الملف من هنا بس ما يحذف المقالة من الموقع.
- لو صار خطأ (مثلًا معادلة مكتوبة غلط أو خانة ناقصة)، GitHub يرسل لك إيميل، وتلقى السبب في
  صفحة **Actions** في المستودع. وتقدر تتأكد قبل الرفع بالأمر:
  `node tools/build-articles.mjs --check content/articles/اسم-الملف.md`
