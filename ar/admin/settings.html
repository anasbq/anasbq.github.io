الإعدادات

المفاتيح تُحفَظ في هذا المتصفح فقط ولا تُرفَع إلى الموقع. إذا فتحت اللوحة من جهاز آخر أدخلها هناك مرة واحدة.

الرمز السري

يقفل اللوحة في هذا المتصفح ويحفظ المفتاحين مشفّرين به، فلا يستطيع من يفتح جهازك النشر أو الحذف دون الرمز. يُطلب الرمز عند كل فتح جديد للمتصفح، وتُقفل اللوحة تلقائياً بعد ٣٠ دقيقة بلا استخدام. لا يمكن استرجاع الرمز إذا نسيته، وعندها تُدخل المفتاحين من جديد.

مفتاح GitHub

مطلوب لنشر المقالات وحذفها وتعديل الصفحات ورفع الصور.

  1. افتح صفحة إنشاء مفتاح Fine-grained.
  2. في «Repository access» اختر Only select repositories ثم anasbq.github.io.
  3. في «Permissions» اجعل Contents على Read and write، ثم أنشئ المفتاح وانسخه.

إحصاءات GoatCounter

من حسابك على GoatCounter: اضغط على بريدك أعلى الصفحة ثم API، وأنشئ مفتاحاً بصلاحية «Read statistics».

النسخة التلقائية

بعض المتصفحات وموانع الإعلانات تمنع الاتصال المباشر بـ GoatCounter. لذلك ينسخ GitHub أرقام الزوار كل نصف ساعة، وتعرضها اللوحة عند الحاجة. تُجهَّز مرة واحدة:

  1. افتح صفحة إضافة سرّ في GitHub.
  2. في «Name» اكتب GOATCOUNTER_TOKEN، وفي «Secret» الصق مفتاح GoatCounter نفسه، ثم Add secret.
  3. افتح صفحة «Update stats» واضغط Run workflow ثم Run workflow مرة أخرى. بعد دقيقة تظهر الأرقام.
